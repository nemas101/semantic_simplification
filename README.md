# semantic_simplification

1. Download the data from gutenberg.org via `download_gutenberg.py`. If run with no arguments it will download a list of 100 books from the gutenberg top 100 engisch book list (list assembled at 14.07.25).
```uv run python download_gutenberg.py```
2. Preprocess the books via `preprocessing.py` script.
```uv run python preprocessing.py```
3. Run the text simplification

4. Compute the different readability scores
